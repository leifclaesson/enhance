# ENHANCE!!

**Zoom, and enhance. Honestly.** A GPU nearest-neighbor screen magnifier and
pixel inspector for Windows -- the "zoom... and **ENHANCE!!**" trope made real,
except it never invents detail: it shows you the *actual* pixels, crisp and
blocky, never a bilinear smear.

### [Download ENHANCE!!](https://leifclaesson.github.io/enhance/)

Or grab the exe straight from
[the latest release](https://github.com/leifclaesson/enhance/releases/latest).
Windows 10 and 11, 64-bit, signed.

## What it does

- Follow-cursor viewport, grabbing the live desktop straight off the GPU
  (DXGI Desktop Duplication) -- zero CPU pixel copies, ~0% load when static
- Clean nearest-neighbor upscaling, 2x..64x, never the blurry bilinear smear
- Pixel inspector: crosshair, grid, live hex/RGB readout, one-key color copy
- Region capture to the clipboard, raw or with the grid baked in
- Inspector Hue: a dedicated still color-pick mode
- Scroll-lock live pin, tray mode, edge-docking as a permanent magnifier rail
- Hidden from screen capture by default, so magnifying over itself never
  creates a hall of mirrors
